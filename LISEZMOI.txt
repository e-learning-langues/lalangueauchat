LA LANGUE AU CHAT : site à mettre en ligne
==========================================

Ce dossier contient le site complet, déjà préparé pour son adresse définitive :
https://e-learning-langues.github.io/lalangueauchat/

Il fonctionne sans base de données ni logiciel à installer. Pour le consulter sur votre ordinateur avant de le publier, ouvrez le fichier index.html dans un navigateur.


1. METTRE LE SITE EN LIGNE SUR GITHUB PAGES

L'adresse ci-dessus suppose un compte (ou une organisation) GitHub nommé « e-learning-langues » et un dépôt nommé « lalangueauchat ». Si l'un des deux noms change, l'adresse change aussi : demandez alors à Claude de régénérer le site avec la nouvelle adresse.

  1. Connectez-vous sur https://github.com avec le compte « e-learning-langues ».
  2. Créez un dépôt public nommé exactement « lalangueauchat » (bouton « New »).
  3. Dans le dépôt, choisissez « Add file », puis « Upload files ». Faites glisser tout le contenu de ce dossier (les fichiers et les dossiers assets, fonts, img, docs, en et es), puis validez avec « Commit changes ».
  4. Ouvrez « Settings », puis « Pages ». Dans « Build and deployment », choisissez « Deploy from a branch », la branche « main » et le dossier « / (root) », puis « Save ».
  5. Après quelques minutes, le site est visible à l'adresse indiquée en haut de ce fichier.

Pour une mise à jour, déposez de nouveau les fichiers modifiés de la même manière : ils remplacent les anciens.
Les intitulés des menus de GitHub peuvent changer au fil du temps.


2. ÊTRE TROUVÉES SUR GOOGLE ET BING

Le site contient déjà tout ce qu'il faut : le plan du site (sitemap.xml), l'adresse de référence de chaque page et la vignette de partage (image du chat et du titre) qui s'affiche quand on colle le lien sur LinkedIn, Teams ou dans un mail.

  1. Google Search Console (https://search.google.com/search-console) : ajoutez une propriété de type « Préfixe d'URL » avec l'adresse complète du site, en terminant par /lalangueauchat/.
  2. Pour prouver que le site est à vous, choisissez la méthode « Fichier HTML » : téléchargez le petit fichier proposé par Google et déposez-le dans le dépôt GitHub, à côté de index.html, comme à l'étape 3 ci-dessus. Revenez ensuite dans Search Console et cliquez sur « Valider ».
  3. Dans le menu « Sitemaps », saisissez sitemap.xml et envoyez.
  4. Bing Webmaster Tools (https://www.bing.com/webmasters) : vous pouvez importer directement le site depuis Google Search Console.
  5. Comptez plusieurs jours, parfois quelques semaines, avant l'apparition dans les résultats.

Ce qui fait le plus pour être trouvées : des liens vers le site depuis des sites reconnus.
  - la page de l'Espace Langues sur le site de l'Université Sorbonne Paris Nord ;
  - le dépôt des affiches sur HAL, avec l'adresse du site ;
  - la page du colloque MEDIALECT, si les organisateurs l'acceptent ;
  - LinkedIn, les listes professionnelles et vos signatures de mail.


3. CONTENU DU DOSSIER

  index.html ............ accueil
  [nom-de-station].html . les sept stations
  en/ ................... version anglaise (mêmes noms de fichiers)
  es/ ................... version espagnole (mêmes noms de fichiers)
  docs/en/, docs/es/ .... fiches de prompts et grilles d'évaluation traduites (PDF)
  catalogue.html ........ toutes les activités, avec recherche et filtres
  404.html .............. page affichée quand une adresse n'existe pas
  sitemap.xml ........... la liste des pages, pour les moteurs de recherche
  assets/ ............... mise en forme et fonctionnement
  fonts/ ................ polices de caractères
  img/ .................. images (dont partage.jpg, la vignette de partage)

4. VERSIONS ANGLAISE ET ESPAGNOLE

Le site existe en trois langues. Le français reste à la racine et sert de version de référence ; l'anglais est dans le dossier en/ et l'espagnol dans le dossier es/. Chaque page porte un sélecteur FR · EN · ES dans l'en-tête, qui mène à la même page dans l'autre langue.

  - Les traductions ont été faites avec Claude à partir du français : une relecture par l'équipe (ou par des collègues anglophones et hispanophones) est conseillée avant de diffuser largement.
  - Quand vous modifiez une page française, pensez à modifier aussi la même page dans en/ et es/, sinon les versions divergent.
  - Pour une mise en ligne, déposez aussi les dossiers en et es, comme à l'étape 3.
  - Les images qui contiennent du texte (captures d'écran, affiches) restent en français ; leurs descriptions (textes alternatifs) sont traduites.
  - Les démos et les défis ne sont pas encore traduits : leurs liens portent la mention « (in French) » / « (en francés) », comme les vidéos et podcasts en français.
  - Dans les cours de FLE, ce que voit l'étudiant reste en français. Les prompts FLE ont deux onglets sur les pages EN et ES : « Original (FR) », affiché par défaut, et « Adaptable », une version traduite et réutilisable dans toute langue cible.
  - Sur les pages EN et ES, les liens « Lire le prompt (PDF) » et « Voir la grille d'évaluation » pointent vers les PDF traduits du dossier docs/ ; le site français garde les liens Google Drive d'origine.
